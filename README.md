# 고려대학교 생명과학부 학생회 사이트

학생회 구성원 전용 사이트입니다. (비상연락망 · 업무 캘린더 · 회의록 모음 · 사업 기획안 · 사업 아카이브 · 가입 승인)

- **설치·인수인계 방법:** `guide.html` 을 브라우저로 열어 보세요. (사이트 주소 뒤에 `/guide.html`)
- **설치 때 고치는 파일:** `js/config.js` 하나뿐입니다.
- **보안 규칙:** `firestore.rules` 내용을 Firebase 콘솔 → Firestore → 규칙에 붙여넣습니다.
- `config.js`가 비어 있으면 연습용 **데모 모드**로 열립니다.

모든 계정(GitHub, Firebase, 회의록 드라이브)은 **학생회 공용 gmail** 하나로 관리합니다.
인수인계 = 공용 gmail 비밀번호 전달 + 사이트 [관리 → 새 학생회로 넘기기]에서 기수·학생회 이름 변경.
